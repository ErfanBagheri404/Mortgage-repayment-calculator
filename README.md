# Mortgage repayment calculator

![Design preview for the Mortgage repayment calculator challenge](./design/desktop-preview.jpg)

Solution to the Frontend Mentor **Mortgage repayment calculator** challenge - a responsive calculator built from the provided design.

**Live demo:** https://erfan-revenant.github.io/Mortgage-repayment-calculator/

## Built with

- Semantic HTML5
- CSS custom properties, Flexbox and media queries
- Vanilla JavaScript for the interactive behaviour (no framework, no build step)
- Bundled webfonts and SVG assets from the challenge starter files

## Run locally

```bash
git clone https://github.com/ErfanBagheri404/Mortgage-repayment-calculator.git
cd Mortgage-repayment-calculator
```

Open `index.html` in a browser. Nothing to install or compile.
